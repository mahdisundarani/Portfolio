## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
1. **Clone the repo**
   ```bash
   git clone https://github.com/mahdisundarani/Portfolio.git
   ```
2. **Install packages**
   ```bash
   npm install
   ```
3. **Set up environment variables**
   Create a `.env` file for your EmailJS and other API keys (refer to `Contact.jsx` for IDs).
4. **Start the development server**
   ```bash
   npm run dev
   ```
5. **Build for production**
   ```bash
   npm run build
   ```
